# Захист матеріалів курсу

1. Виконай `secure-content.sql` у Supabase SQL Editor.
2. Відкрий Storage → bucket `course-content`.
3. Завантаж файл `cabinet-content.html` з кореня проєкту саме з назвою `cabinet-content.html`.
4. Перевір у приватному вікні: без входу файл не має завантажуватися; з оплаченим акаунтом — має.
5. После проверки `cabinet-loader.js` уже можно переключить на приватный Storage; публичная копия из GitHub Pages удаляется на этом этапе.

До выполнения шагов 1–4 не переключай loader на Storage, иначе живой кабинет не загрузит материалы.
