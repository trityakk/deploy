## Конкретные оставшиеся риски

- Webhook содержит неподдерживаемый getUserByEmail и сбрасывает пароль существующему пользователю при повторной обработке без отметки отправки. Нужны отдельная доработка идемпотентности и тесты; платёжные настройки/заказы в этом этапе не менялись.
- Lighthouse CLI зависает при запуске в этом окружении; оценок производительности нет. Не считать мобильный viewport тестом физического Safari.
- Чтение настройки GitHub Pages через сохранённый токен заблокировано проверкой разрешений; токен не извлечён. Обычный git ls-remote работает.
